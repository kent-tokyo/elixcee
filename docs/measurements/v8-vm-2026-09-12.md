# V8 native VBA VM measurement — 2026-09-12

This is a local execution-only baseline for the native VBA VM. It is not a
comparison with Excel, xlflow, openpyxl, or any other library.

## Protocol

- build: `elixcee` v1.0.12 release binary
- host: local macOS arm64 host; host details are not normalized for a
  cross-machine claim
- workload: parse one `For`/cell-write program once, then execute it in a new
  `Vm` per sample for 10,000 rows
- timed boundary: `Vm::run_sub` only; parser, workbook I/O, and JSON output are
  excluded
- warmup: 5
- measured repetitions: 30
- command:

```sh
cargo run --release --bin benchmark_vba_vm -- \
  --rows 10000 --warmup 5 --repetitions 30
```
