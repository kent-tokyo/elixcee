# Python date1904 contract check

Date: 2026-09-10 (Asia/Tokyo)

This check runs the installed Python wheel, rather than only compiling the
PyO3 feature. It creates a valid streamed XLSX, inserts
`workbookPr@date1904="1"`, loads it through `elixcee.load_workbook()`, and
checks that a subsequent Python save preserves the flag.

## Result

- Host: macOS arm64
- Python: CPython 3.13
- Wheel: locally built `elixcee-1.0.5-cp313-cp313-macosx_11_0_arm64.whl`
- Environment: isolated temporary venv, no dependency installation
- Test file: `tests/python/test_stream_writer_limits.py`
- Tests: 11 passed, 0 failed
- Result: the date1904 metadata contract passed in the real wheel

## Reproduction

```sh
maturin build --features python --offline -o /private/tmp/elixcee-wheel-test
python3 -m venv /private/tmp/elixcee-test-venv
/private/tmp/elixcee-test-venv/bin/pip install --no-deps \
  /private/tmp/elixcee-wheel-test/elixcee-1.0.5-cp313-cp313-macosx_11_0_arm64.whl
/private/tmp/elixcee-test-venv/bin/python \
  tests/python/test_stream_writer_limits.py
```

This is a local macOS wheel check. It does not establish Linux/Windows wheel
compatibility, Excel compatibility, or conversion of 1904 serial values.
